# OOU Students' Union Health Hub

A responsive, static website prototype for the Office of the Medical Director, OOU Students' Union.

## Included
- Responsive homepage and mobile navigation
- Health education cards
- Programmes and events preview
- Four-campus directory placeholder: Ago-Iwoye, Sagamu, Aiyetoro and Ibogun
- Question, volunteer and feedback form prototypes
- Institutional identity with current officeholder kept separate
- SUG and OOU logo assets

## Important before public launch
The question, volunteer and feedback forms are front-end demos only. They do not send or store data. Connect and test an appropriate secure form/backend service before collecting real submissions. Review privacy notices, data retention, access controls and any relevant Nigerian data-protection requirements. Verify healthcare facility details and emergency contacts before publishing them. Have health information reviewed by a qualified healthcare professional.

## Preview locally
Open `index.html` in a modern browser.

## Free static hosting
This project can be hosted on GitHub Pages. Create a repository, upload the files while preserving the `assets` folder, then enable Pages in the repository settings. The free Pages address will be based on your GitHub username and repository name.

## Updating the officeholder
In `index.html`, edit the “Meet the Medical Director” block in the `director-profile` section to add the current officeholder's approved name, photo and short profile. Keep the main brand and website identity institutional for future handover.
